# Title-screen art & video

The title screen loads its picture and looping video from Higgsfield online.
To make them work offline, save them here as `title.png` and `title.mp4` and commit.
Files in this folder are used first; if none load, the game's own drawn title screen appears.
Character voice lines work the same way: files like `voice/title1.mp3` or `voice/ok1.mp3` are used before the online copies.
